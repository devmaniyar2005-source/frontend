# what is IDE list out all type of IDE ?

1. IDE is a software application that provides comprehensive facilities to computer programmers for software development i.e called IDE
2. IDE normally consists of at least a source code editor, build automation tools, and a debugger i.e called IDE
3. IDE is three types ...

**types of IDE**

1. desktop IDE
2. cloud IDE
3. mobile IDE

# desktop IDE ...

1. IDE which is installed directly on a developer's local computer and runs offline i.e called desktop

    **examples**

    ```
    Visual Studio
    ```


# cloud IDE ...

1. IDE which is hosted on a remote server and accessed entirely through a web browser i.e called cloud

    **examples**

    ```
    https://replit.com/
    ```

    or

    ```
    https://github.com/features/codespaces
    ```

# mobile IDE ...

1. IDE which is designed specifically to run on smartphones or tablets for coding directly on mobile devices i.e called mobile

    **examples**

    ```
    AIDE (Android IDE)
    ```
