# what is URL  ?

1. URL (Uniform Resource Locator) is a specific web address used to identify and locate files, pages, or resources on the internet i.e called URL
2. URL normally consists of multiple parts including a protocol (like HTTP or HTTPS), a domain name, and a file path i.e called URL
3. URL is four main types ...

**types of URL**
1. Absolute URL
2. Relative URL
3. Static URL
4. Dynamic URL

# Absolute URL ...

1. URL which contains all the complete information needed to find a resource, including the protocol and the full domain name i.e called absolute

    **examples**

    ```
    https://www.google.com/
    ```
 

# Relative URL ...

1. URL which only contains the path to a file relative to the current web page or directory, without the protocol or domain name i.e called relative

    **examples**

    ```
    /images/logo.png
    ```


# Static URL ...

1. URL which remains constant, does not change, and points to a specific, hardcoded web page or file without any parameters i.e called static

    **examples**


    ```
    https://www.saurashtrauniversity.edu/syllabus
    ```

# Dynamic URL ...

1. URL which is generated on the fly from a database and contains query strings or parameters (like `?id=123`) to load variable content i.e called dynamic

    **examples**

    ```
    https://www.youtube.com/watch?v=dQw4w9WgXcQ
    ```
