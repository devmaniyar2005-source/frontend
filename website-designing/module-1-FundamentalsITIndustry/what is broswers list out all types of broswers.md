# what is Browser list out all types of Browser ?
1. Browser is a software application used to access, retrieve, and view information on the World Wide Web i.e called Browser
2. Browser translates HTML, CSS, and JavaScript from web servers into a readable graphical interface for the user i.e called Browser
3. Browser is three main types ...

**types of Browser**
1. Graphical (Desktop) Browser
2. Mobile Browser
3. Text-based Browser

# Graphical Browser ...

1. Browser which uses a graphical user interface (GUI) to display text, images, and videos, typically installed on personal computers i.e called graphical

    **examples**

    ```
    Google Chrome
    ```


# Mobile Browser ...

1. Browser which is specifically optimized to display web content efficiently on smaller touch-screens and mobile operating systems i.e called mobile

    **examples**


    ```
    Chrome for Android
    ```

# Text-based Browser ...

1. Browser which runs entirely within a terminal or command-line interface and renders only the text of a webpage without any images or styling i.e called text-based

    **examples**

    ```
    Lynx
    ```
