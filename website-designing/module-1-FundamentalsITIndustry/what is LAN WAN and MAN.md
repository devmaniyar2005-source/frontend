# what is Network list out all type of Network ?
1. Network is a collection of computers and devices connected together to share resources and data i.e called Network
2. Network allows communication between different devices over short or long distances i.e called Network
3. Network is three types ...

**types of Network**
1. LAN (Local Area Network)
2. MAN (Metropolitan Area Network)
3. WAN (Wide Area Network)

# LAN (Local Area Network) ...

1. Network which is confined to a small geographic area like a single room, office, or university campus i.e called LAN

    **examples**

    ```
    Home Wi-Fi
    ```

   

# MAN (Metropolitan Area Network) ...

1. Network which connects multiple LANs and covers a larger geographic area like a whole city or town i.e called MAN

    **examples**

    ```
     Cable TV Network
    ```

    

# WAN (Wide Area Network) ...

1. Network which covers a massive geographic area spanning across regions, countries, or the entire globe i.e called WAN

    **examples**

    ```
    The Internet
    ```
